# 🌍 Earthquake Dashboard

Interactive dashboard to explore global earthquake distribution using USGS data.

**Live app:** [earthquake-dashboard.streamlit.app](https://earthquake-dashboard.streamlit.app)

Built with Streamlit + Plotly · Data: [USGS Earthquake Hazards Program](https://earthquake.usgs.gov)

**Features:**
- Filter by year range and minimum magnitude
- Annual counts by magnitude category
- Global epicenter map
- Magnitude & depth distributions
- Yearly trends + Top 10 largest earthquakes
